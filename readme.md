# [0-1系列] 0-1 实现一个神经网络
为了自我学习和成长，我计划开始一个0-1系列，用于实践自己所学习到的知识
本项目是0-1实现一个神经网络。本项目会逐渐增加功能，从最解决最简单的问题（XOR），逐渐过渡到解决复杂问题（图片识别）
在这个过程中，我尝试完全不使用任何现有的神经网络库，仅使用NumPy来实现神经网络的前向传播和反向传播。（数据集还是会用开源的）

学习路径：
1. 最简单神经网络：解决XOR -> 入门
2. 全连接神经网络：用MNIST训练识别手写数字 -> 巩固全连接神经网络的知识
3. 卷积神经网络：人脸识别 -> 学习卷积神经网络，学习特征提取和池化
4. 循环神经网络： -> 理解记忆和时序特性
5. 自编码器：  -> 无监督学习和特征压缩
6. Transform： -> 理解Transform架构，实现Attention计算
7. 微调开源的大模型：-> 理解大模型的应用
